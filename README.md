# TokoKita
Buka `index.html` di browser (Chrome/Edge disarankan). Tanpa instalasi. Data tersimpan di localStorage browser.
Uji dua peran: daftar sebagai Penjual di satu tab, sebagai Pembeli di tab lain.
Catatan: ini demo front-end. Login Gmail, lupa sandi, dan live masih simulasi; untuk produksi perlu backend (Firebase/Supabase/Node).
